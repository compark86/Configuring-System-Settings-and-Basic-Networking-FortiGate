# FortiGate CLI Commands

## Task 2: Configure and monitor the default route

### 1. Configure port6 (WAN) interface:

config system interface
    edit "port6"
        set mode static
        set ip 172.16.20.1 255.255.255.252
        set allowaccess ssh ping
        set role wan
        set description "WAN port connected to ISP"
    next
end

### 2. Configure default static route:

config router static
    edit 1
        set device "port6"
        set gateway 172.16.20.2
        set dst 0.0.0.0 0.0.0.0
    next
end
